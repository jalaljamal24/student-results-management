# نظام إدارة وتحليل نتائج الطلاب

هذا المشروع يطبق نموذجًا بسيطًا لنظام إدارة الطلاب باستخدام JavaScript، ويشمل:

- كلاس Student
- استخدام map، filter، و reduce
- حساب المتوسط والتقدير والحالة النهائية
- عرض تقرير كامل للطلاب عبر Console
- تطبيق سياسة الرأفة على الطلاب المتعثرين

## التشغيل

```bash
node src/index.js
```

## الاختبارات

```bash
node --test
```
