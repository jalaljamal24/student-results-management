# نظام إدارة وتحليل نتائج الطلاب

لوحة أكاديمية باللغة العربية لتحليل نتائج الطلاب، تلخيص الأداء، وتحديد الحالات المستحقة لدرجات الرأفة. صُمم المشروع كتطبيق JavaScript صغير يجمع بين البرمجة كائنية التوجه ودوال المصفوفات، ويعرض التقرير في Console المتصفح مع واجهة مرئية متجاوبة.

## المزايا

- حساب متوسط الدرجات والتقدير بالحروف لكل طالب.
- تحديد النتيجة النهائية وفق المتوسط ونسبة الحضور.
- استخراج الطلاب الذين تتراوح متوسطاتهم بين 40 و49 وتطبيق خمس درجات رأفة.
- عرض ملخص النتائج والجداول الأكاديمية بالعربية، مع دعم اتجاه الكتابة من اليمين إلى اليسار.
- حماية حساب متوسط الرأفة عندما لا يوجد طلاب متعثرون.
- اختبارات آلية لقواعد التقدير والنجاح والرأفة.

## المتطلبات

- Node.js 20.19 أو أحدث، أو 22.12 أو أحدث.
- npm.

## التشغيل المحلي

لا تفتح `index.html` مباشرة؛ شغّل خادم التطوير كي تُحمّل وحدات JavaScript:

```bash
npm ci
npm run dev
```

افتح رابط localhost الذي يظهر في الطرفية. تقرير الـConsole متاح في أدوات المطور بالمتصفح، ويمكن تشغيله مباشرةً في Node.js باستخدام:

```bash
npm start
```

## الاختبارات والبناء

```bash
npm test
npm run build
```

يُنشأ إصدار الإنتاج في مجلد `dist/`.

## قواعد النتائج

- المتوسط هو مجموع درجات المواد مقسومًا على عددها.
- حدود التقدير: A من 90، B من 80، C من 70، D من 60، E من 50، وما دون ذلك F.
- النجاح يتطلب متوسطًا لا يقل عن 50 وحضورًا لا يقل عن 75%.
- تُضاف خمس درجات إلى متوسط الطالب الذي يقع متوسطه من 40 إلى 49، لأغراض تقرير الرأفة.
- الأسماء والدرجات الحالية بيانات تجريبية، ويمكن تعديلها في `src/index.js`.

## هيكل المشروع

```text
index.html
src/
  Student.js          # نموذج الطالب وقواعد التقدير والنتيجة
  academicReport.js   # تحليل النتائج والرأفة
  index.js            # بيانات العرض وتقرير Console والواجهة
  styles.css          # تنسيقات الواجهة المتجاوبة
tests/
  student.test.js
.github/workflows/
  deploy.yml          # البناء والنشر إلى GitHub Pages
```

## النشر على GitHub Pages

ارفع ملفات المشروع إلى فرع `main`، ثم اختر **GitHub Actions** مصدرًا للنشر من **Settings → Pages**. ينفّذ GitHub Actions الاختبارات والبناء وينشر محتويات `dist/` عند الدفع إلى الفرع.
