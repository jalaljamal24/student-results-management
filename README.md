# نظام إدارة وتحليل نتائج الطلاب

هذا المشروع يطبق نموذجًا بسيطًا لنظام إدارة الطلاب باستخدام JavaScript، مع:

- كلاس `Student`
- دوال `map`, `filter`, `reduce`
- حساب المتوسط والتقدير والنتيجة النهائية
- تقرير console كامل للطلاب
- تطبيق "رأفة" على الطلاب المتعثرين

## التشغيل

```bash
node src/index.js
```

## الاختبارات

```bash
node --test
```
