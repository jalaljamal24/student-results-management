# نظام إدارة وتحليل نتائج الطلاب

محرك JavaScript لإدارة وتحليل نتائج الطلاب باستخدام البرمجة كائنية التوجه ودوال المصفوفات `reduce` و`filter` و`map`. يعرض التقرير الأكاديمي الكامل في Console المتصفح، مع صفحة مرئية اختيارية لعرض النتائج.

## المتطلبات

- Node.js 20.19 أو أحدث، أو 22.12 أو أحدث
- npm

## التشغيل المحلي

لا تفتح `index.html` مباشرة بعد فك الضغط؛ شغّل خادم التطوير أولًا:

```bash
npm ci
npm run dev
```

افتح رابط localhost الذي يظهر في الطرفية. لعرض سجل التنفيذ، افتح أدوات المطور في المتصفح ثم تبويب Console. يتطلب التشغيل Node.js 20.19 أو أحدث، أو 22.12 أو أحدث، وnpm.

لتشغيل التقرير مباشرة في طرفية Node.js:

```bash
npm start
```

## الاختبارات والبناء

```bash
npm test
npm run build
```

## النشر

ارفع محتويات المشروع إلى فرع `main`، ثم من إعدادات المستودع افتح **Settings > Pages** واختر **GitHub Actions** كمصدر النشر. بعدها يبني GitHub Actions الموقع وينشره تلقائيًا عند كل دفع إلى `main`. رابط الموقع يظهر في إعدادات Pages بعد اكتمال النشر.

## قواعد النتائج

- المتوسط هو مجموع الدرجات مقسومًا على عدد المواد.
- التقديرات: A من 90، B من 80، C من 70، D من 60، E من 50، وما دون ذلك F.
- النجاح يتطلب متوسطًا لا يقل عن 50 وحضورًا لا يقل عن 75%.
- تُضاف 5 درجات إلى متوسط الطالب الذي يقع متوسطه بين 40 و49.
